ShakeFlash — design reference

This is a browser mock of the Android UI so you can see and feel the button press + sliding sheen, the sliding switch thumb, the sliding slider and the glowing power dial before building.

The real app is the Kotlin/Compose project in this repo. Nothing here is part of the APK.

  • Tap the dial → torch state, chip, glow, warning row
  • Flip the switch → listening bars start/stop
  • Drag the slider → sensitivity chip updates
  • Tap ⚙ → settings bottom sheet slides up

Colours, radii and timings mirror ui/theme and ui/components.
